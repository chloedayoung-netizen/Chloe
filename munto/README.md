## 2차 검토(대표 시점 레드팀)에서 바꾼 것

- **판정: 조건부 Yes** — "만들어 내놓고 판정 기준을 미리 적었다"가 다른 지원자와 가르는 점. 단, **지인 아닌 사용자 10명 이상 + 실사용 캡처**가 없으면 No.
- 사실 정정: "혼자" → "한 사람이", KYB "이전" → "이전 진행", 근거 없는 연결 문장 삭제, 출처 각주 추가
- 자소서 2번 소재 교체: 리셀러 운영자 설득(결과가 계약 아님) → **신규 고객군 재정의로 3곳 계약**(채널 시도 → 접음 → 직접 접근, 공고의 '초기 고객 확보'와 직결)
- 자소서 1번: "모르는 사람이 돈 내게 한 적 없음"을 첫 문단에서 빼고 MVP 결과 뒤로
- 포트폴리오 3쪽: 동료 도구 표 → **대화 발췌 3개, 경로별 숫자, 버린 것, 문토 연결 가설**
- MVP 보강: 캘린더 알림(재방문 채널), 다시 와야 깊어지는 친밀도, 탐정 사건 바이블, 실험용 실제 송금 링크(첫 매출), "장르 한 변수"가 아니라 "세 콘셉트 비교"로 정직하게
- **저장소 공개 주의**: 이 저장소에는 다른 회사(CoeFont) 지원 서류가 함께 있다. 포트폴리오에 링크할 때는 `munto/mvp`만 새 공개 저장소로 옮겨 링크한다
- 결과가 나쁘게 나와도 점수가 오르는 쓰기: **숫자 → 로그에서 본 원인 → 바꾼 것 → 재측정 → 다음 결정** 다섯 칸을 다 채운다 (포트폴리오 2쪽 표). 통과선: 비지인 10명+, 경로별 숫자, p1→p2 비교 1건, 버린 것 1개
