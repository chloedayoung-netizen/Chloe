# 정주영 창업경진대회 랜딩 — 디자인 레퍼런스

원본: https://startup.asan-nanum.org (2026 행사 페이지, Next.js + CSS Modules, Figma 기반 제작)
소스: 브라우저 "다른 이름으로 저장"한 HTML에서 추출

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 정리된 마크업. 스크립트·추적 코드·브라우저 확장 프로그램(DeepL, ChatGPT 사이드바 등)이 주입한 스타일과 요소는 제거함. 에셋 경로는 `./assets/`로 통일 |
| `assets/` | **비어 있음.** 원본 저장 시 함께 생긴 `정주영 창업경진대회_files/` 폴더 내용을 여기에 넣으면 CSS·이미지가 연결됨 |

> 실제 스타일시트(`2sikkleqdgd2n.css`, `37n2w_cyuw1h4.css`)는 `_files` 폴더에만 있어 아직 확보되지 않았습니다.
> 아래 디자인 토큰은 HTML 인라인 스타일과 구조에서 확인 가능한 값만 적었습니다.

## 디자인 토큰 (확인된 값)

| 용도 | 값 |

| 프로그램: Global | `#8278FF` (퍼플) |

프로그램 컬러는 탭에 `--tabColor`, 카드에 `--cardColor`로 CSS 변수를 주입하는 방식입니다. 컬러 하나만 바꾸면 컴포넌트 전체 테마가 바뀝니다.

### 타이포그래피
- 한글: **Pretendard Variable** (`pretendardvariable-dynamic-subset`), 변수 `--font-kr`
- 영문 디스플레이: Google Fonts(`css2`) 별도 로드. 폰트명은 CSS 확보 후 확인 필요
- 섹션 타이틀은 영문 한 단어를 씀 (About / Startups / Perks / FAQ / Heritage)
- 인용 섹션 기준: 본문 56px / 행간 80px, 서명 28px / 30px (1920 아트보드 기준)

### 스케일링
- `--s` 변수 = 뷰포트 너비 ÷ 1920 아트보드. 인용 섹션은 Figma 좌표를 그대로 `calc(N * var(--s))`로 배치해 픽셀 단위로 정확히 재현함
- 모바일 분기점: `max-width: 1023.98px`
- 이미지 크롭도 변수로 제어: `--crop-size`, `--crop-pos`, `--photo-m*` (모바일 크롭)

## 페이지 구성 (위→아래)

1. **GNB**: 로고 / About·Startups·Perks·FAQ 앵커 / EN 토글 / `참가하기` CTA / 모바일 햄버거
2. **Hero (KV)**: 풀스크린 `<canvas>` 인터랙티브 비주얼(카피 "인간의 가능성은 무한하다"는 스크린리더용 텍스트로만 존재). 하단에 일시·장소 + 스크롤 화살표
3. **Floating CTA**: 스크롤 시 나타나는 알약형 바 (`참가하기` | 공유 버튼)
4. **About**: 좌측 영문 H2 + 우측 리드 문단 → 카드 3장 (태그 `도전/성장/나눔` + 제목 + 설명). 데스크톱은 가로 크롭, 모바일은 정사각 이미지 별도 사용
5. **Opening Film**: sticky 컨테이너, 스크롤 진행률 `--p`(0–1)에 따라 영상 박스 확대. 클릭으로 사운드 토글
6. **Startups**: 프로그램 탭 4개(컬러 코딩) → 태그라인 → 팀 카드 그리드(팀명·대표·설명·사진·`+`). 카드별 **응원하기** 투표 버튼
7. **Perks**: 파트너 로고 10개 그리드. 로고를 누르면 오른쪽 패널에 혜택 카드가 교체됨 (`aria-pressed`, `aria-live`)
8. **FAQ**: 카테고리 탭 3개 + 아코디언 (chevron은 `<i>` 두 개로 만든 X/V 모핑)
9. **Quote**: 아산 정주영 어록. 텍스트 줄 사이에 사진 "창(window)"이 끼어드는 에디토리얼 레이아웃, 프레임 순차 등장 애니메이션(`--quote-duration: 950ms`). 모바일은 행 단위 플로우 레이아웃으로 따로 구현
10. **Heritage**: 스크롤 고정 타임라인. 2012–2025, 15단계(`--heritage-step: 30vh`). 좌측 연도 / 중앙 사진 스택(current·next·waiting 슬롯이 확대되며 교체) / 우측 회차 + 캡션 리빌. 모바일은 가로 트랙
11. **Footer**: 재단 프로그램 로고 바(SVG 1장 위에 투명 링크를 좌표로 얹음) / 재단 소개 / SNS / 개인정보처리방침·이메일·카피라이트

## 재사용할 만한 패턴

- **CSS 변수로 테마 주입**: 탭·카드마다 `style="--cardColor:…"`를 넣어 컴포넌트 하나로 여러 컬러 테마를 처리
- **Figma 좌표를 그대로 옮기는 스케일 시스템**: `--s` 하나로 데스크톱 아트보드를 비율 그대로 재현하고, 모바일은 별도 마크업으로 처리
- **스크롤 진행률 연동 섹션**: sticky + `--p`/`data-pos` 같은 진행률 변수로 영상 확대, 사진 스택 전환
- **텍스트 리빌**: `.reveal` 래퍼로 줄 단위 마스크 등장
- **접근성**: `srOnly` 대체 텍스트, `role="tablist"/"tab"`, `aria-expanded`, `aria-pressed`, `aria-live`를 일관되게 사용

## 사용 시 주의

- 로고, 사진, 영상, 카피는 아산나눔재단 소유입니다. 다른 프로젝트에는 **구조·레이아웃·인터랙션 패턴만** 참고하고, 에셋과 브랜딩은 교체해서 쓰세요.
- 인터랙션(Hero 캔버스, 스크롤 연동 등)은 JS 번들(`_files/*.js`)에 있고 압축되어 있습니다. 직접 재구현하는 편이 현실적입니다.
